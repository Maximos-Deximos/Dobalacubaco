# Decisão 001
Data: 10/11/2026
Decisão: Funcionamento do agente
Status: Aceito

### Segurança
O agente não deve realizar autenticação em sites que requerem logina antes do preenchimento de 
um edital
O agente não envia os editais sozinho. (requer autorização de usuario)

### UI:
O projeto é um mvp, por esse motivo acho mais viavel o funcionamento da interface através de CLI
(com brecha para utilização de fastAPI futuramente)

### Usuarios
Como MVP apenas um perfil único de usuario será desenvolvido mas a arquitetura irá suportar 
múltiplos

### Técnicos
Projeto deve seguir a norma open source, mas com comentarios, documentalçao em português para 
facilitar comunicação entre membros da equipe.

### Local de testes
O software será testado em editais publicos ou editais criado pela equipe
